Install Track Anything

Add Track Anything to your Home Screen, or install it, for a convenient way to open it. It then opens in its own window.

Show steps for

Installation steps depend on the device. Not every browser can install the site.

iPhone and iPad

  1. Open the Share menu, marked with the Share icon {{icon "share-up"}}. In some Safari layouts, Share is inside the Page Menu.
  2. Choose Add to Home Screen. You may need to scroll through the actions.
  3. If Open as Web App appears, leave it enabled.
  4. Tap Add.

Having trouble? Open this page in Safari and follow these steps.

Android

The browser menu may include Install app or Add to Home screen. The label varies, and not every browser offers it.

Computer

A supported browser may show an install icon in the address bar, or an installation option in its menu. Not every browser can install the site.

This page may be open inside another app. If you do not see a way to install, use that app's menu to open it in a full browser.
